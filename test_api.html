Test API Synchronisation

Collez le contenu HTML de la page audio.com ci-dessous et cliquez sur "Envoyer".

Exemple d'utilisation (JavaScript)

// Envoyer via fetch
fetch('https://crash8.fr/audio/actions/api_sync.php', {
    method: 'POST',
    headers: {
        'Content-Type': 'application/json'
    },
    body: JSON.stringify({
        html: htmlContent
    })
})
.then(response => response.json())
.then(data => {
    console.log('Succès:', data);
})
.catch(error => {
    console.error('Erreur:', error);
});

// Ou via FormData
const formData = new FormData();
formData.append('html', htmlContent);

fetch('https://crash8.fr/audio/actions/api_sync.php', {
    method: 'POST',
    body: formData
})
.then(response => response.json())
.then(data => console.log(data));

Exemple d'utilisation (cURL)

curl -X POST https://crash8.fr/audio/actions/api_sync.php \
  -H "Content-Type: application/json" \
  -d '{"html":"<html>...</html>"}'
